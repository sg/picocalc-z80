# picocalc-z80

picocalc-z80 runs Udo Munk's [z80pack](https://github.com/udo-munk/z80pack) Z80/8080 simulator on the [ClockworkPi PicoCalc](https://www.clockworkpi.com/picocalc), turning it into a pocket CP/M machine with its own screen, keyboard and MicroSD disk images. It builds for the Raspberry Pi Pico, Pico W, Pico 2, Pico 2 W and Pimoroni Pico Plus 2 W. On the WiFi boards a virtual Hayes modem lets CP/M dial telnet BBSes and answer incoming calls, and the clock sets itself from NTP.
