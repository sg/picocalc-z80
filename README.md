# picocalc-z80
## A PicoCalc Z80/8080 simulator 

picocalc-z80 is based on Udo Munk's [z80pack](https://github.com/udo-munk/z80pack) Z80/8080 simulator and his [Pico-Eval-Board-80](https://github.com/udo-munk/Pico-Eval-Board-80) project. The hardware layer is replaced with drivers and code supporting the [ClockworkPi PicoCalc](https://www.clockworkpi.com/picocalc), turning it into a pocket Z80 machine with its own screen, keyboard, network stack, and disk images allowing CP/M and other operating systems to run faithfully. It builds for the Raspberry Pi Pico, Pico W, Pico 2, Pico 2 W and Pimoroni Pico Plus 2 W. On the WiFi boards a virtual Hayes modem lets CP/M dial telnet BBSes and answer incoming calls, and the clock sets itself from NTP.

The WiFi builds can update themselves. `U - Update PicoCalc-Z80` on the main menu takes the address of the project's release page, checks it for a newer version, downloads the firmware for your board into the directory that pelrun's [uf2loader](https://github.com/pelrun/uf2loader) reads, and brings the `/Z80` files on the card up to date, backing up any disk image you have written to. HTTPS works on the Pico 2 boards; the Pico W uses plain HTTP. `DEV_NOTES.md` has the details, the card layout and the build instructions.
